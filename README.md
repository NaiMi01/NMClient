# NMClient · NM客户端
基于 [DDNet](https://github.com/ddnet/ddnet) 开发的自定义客户端，提供界面改造、地图预览和游戏体验优化。

## 主要功能

- **游戏内灵动岛**：音乐信息、歌词和天气展示。
- **旁观卡片**：分数、玩家信息及按键可视化，支持字体设置。
- **服务器地图预览**：后台加载地图缩略图，方便挑选服务器。
- **视觉美化**：角色拖尾、终点卡片等效果。
- **自定义音效**：导入、切换音效及波形预览。

## 使用方法

1. 在本仓库的 **Releases** 页面下载客户端发布包。
2. 解压后运行 `NMClient.exe`，保留发布包中的资源和依赖文件。
